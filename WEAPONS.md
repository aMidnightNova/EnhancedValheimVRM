# Weapons you can move

These are the item names the game uses. Put one in front of the number in a weapon line in your settings file, or use the class word to move the whole group. See the README for how the lines work.

```
BowPos=BowDraugrFang,<0, 0.03, 0>
```

The class word is the heading. Anything not listed here (modded weapons) still works, the mod sorts it into a class from the games own item data.

### Rigged
These come with their own hand rig, so the lines above do nothing for them. Each piece gets its own line instead, e.g. `KnifeSkollAndHatiLeftHandPos=<0, 0.01, 0>`, using LeftHand, RightHand, LeftForeArm or RightForeArm. Only the Knucklechains (FistGold ones) have forearm pieces.
